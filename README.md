# Hala Concierge - Voice of the Oasis Hackathon 

### DSO already has 340+ online services and a text chatbot (HADI). What it lacks is a voice that HR/PRO staff and residents can talk to in Arabic or English. The voice should know which service applies, tell them what they need, and book the next step. It runs on Humanoid Robot B (MangoBot controls all movement; we only build the voice) at the HALA reception, with a phone line as a stretch.
